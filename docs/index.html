How your secrets are kept

  1. One master passwordIt is stretched with Argon2id, which makes every guess slow and memory-hungry. It is never stored.
  2. A key only you can unwrapThe password unwraps a random master key. Nothing else can.
  3. Two layers of armourSQLCipher encrypts the whole database; XChaCha20-Poly1305 seals each password and note.
  4. Forgotten on lockWhen Pangolin locks, the keys are wiped from memory.

  • The builds are not code-signed yet, so Windows SmartScreen and macOS Gatekeeper will warn the first time you open Pangolin.
  • On macOS, if it refuses to open: System Settings → Privacy & Security → Open Anyway.
  • The Linux .tar.gz contains install.sh, which adds Pangolin to your application menu without root.
  • Each release lists SHA-256 checksums. All releases and checksums

Two honest things

There is no password recovery. If you forget the master password, nobody can open the vault, including us.

Pangolin is new. It uses standard, well-reviewed cryptography, but it has not had an independent security audit yet. Keep a backup of anything you cannot afford to lose.
